# eShopPlus Mobile App - Project Information & Troubleshooting Guide

## Project Overview
**eShopPlus** is a comprehensive Flutter-based e-commerce mobile application (Version 1.0.6) designed for customers to browse, purchase, and manage orders from multiple stores. The app provides a complete shopping experience with features like product discovery, cart management, multiple payment options, order tracking, and customer support.

## Technical Specifications
- **Framework**: Flutter (>=3.7.0)
- **Dart SDK**: >=3.3.0 <4.0.0
- **Architecture**: BLoC (Business Logic Component) pattern
- **State Management**: flutter_bloc
- **Local Storage**: Hive database
- **Backend API**: RESTful API
- **Firebase Integration**: Authentication, Messaging, Core
- **Package Name**: 
  - Android: com.sanwariya.customer
  - iOS: com.wrteam.eshop.pro

## Core Features & Functionality

### 1. Authentication System
**Location**: `lib/ui/auth/`

**Features**:
- Google Sign-In integration
- Apple Sign-In support
- Phone number authentication
- Guest user mode
- Firebase Authentication backend

**Key Components**:
- `AuthCubit`: Manages authentication state
- `AuthRepository`: Handles authentication operations
- `SignInCubit`: Manages sign-in process
- `SignUpCubit`: Manages user registration

**Troubleshooting**:
- **Login Issues**: Check Firebase configuration in `firebase_options.dart`
- **Google Sign-In Fails**: Verify SHA-1 fingerprints in Firebase console
- **Apple Sign-In Issues**: Ensure proper Apple Developer account setup
- **Token Expiry**: Check token refresh mechanism in `AuthRepository`

### 2. Main Navigation & Home Screen
**Location**: `lib/ui/mainScreen.dart`, `lib/ui/home/`

**Features**:
- Bottom navigation with 5 tabs: Home, Categories, Explore, Cart, Profile
- Home screen with multiple sections:
  - Product sliders/banners
  - Category sliders
  - Featured sellers
  - Most selling products
  - Offers and promotions
  - Brand sections

**Key Components**:
- `MainScreen`: Main navigation container
- `HomeScreen`: Home page with product sections
- `SliderCubit`: Manages banner/slider data
- `CategorySliderCubit`: Handles category display
- `FeaturedSellerCubit`: Manages featured sellers
- `MostSellingProductsCubit`: Handles best-selling products

**Troubleshooting**:
- **Navigation Issues**: Check route definitions in `lib/core/routes/routes.dart`
- **Home Screen Not Loading**: Verify API endpoints in `lib/core/api/apiEndPoints.dart`
- **Slider Not Working**: Check image URLs and network connectivity
- **Categories Not Showing**: Verify category API response format

### 3. Product Management & Discovery
**Location**: `lib/commons/product/`, `lib/ui/explore/`

**Features**:
- Product listing with filters (price, brand, category, rating)
- Search functionality with autocomplete
- Product details with variants, images, reviews
- Similar products suggestions
- Product comparison
- Wishlist/favorites management
- Combo products support

**Key Components**:
- `ProductsCubit`: Manages product data
- `ComboProductsCubit`: Handles combo products
- `ProductRepository`: API calls for products
- `ProductDetailsScreen`: Individual product view
- `ExploreScreen`: Product discovery and filtering

**Troubleshooting**:
- **Products Not Loading**: Check API connectivity and store ID
- **Search Not Working**: Verify search API endpoint
- **Filters Not Applied**: Check filter parameter formatting
- **Product Images Not Loading**: Verify image URLs and CDN
- **Wishlist Issues**: Check Hive database initialization

### 4. Shopping Cart System

- Add/remove products from cart

**Key Components**:

- `GetUserCartCubit`: Fetches user cart

**Troubleshooting**:
- **Cart Not Saving**: Check Hive database initialization
- **Quantity Update Fails**: Verify cart API parameters
- **Promo Code Not Working**: Check promo code validation logic
- **Delivery Charges Wrong**: Verify address and delivery zone settings
- **Cart Sync Issues**: Check user authentication state

## Data Storage & Management

### Local Storage (Hive)
**Location**: `lib/core/constants/hiveConstants.dart`

**Storage Boxes**:
- `authBoxKey`: User authentication data
- `settingsBoxKey`: App settings and preferences
- `cartBoxKey`: Cart items (CartItem model)
- `productsBoxKey`: Cached product data
- `favoritesBoxKey`: User favorites
- `promocodeBoxKey`: Promo codes
- `searchBoxKey`: Search history

**Troubleshooting**:
- **Data Not Persisting**: Check Hive initialization in `main.dart`
- **Cart Data Lost**: Verify CartItem adapter registration
- **Settings Reset**: Check SharedPreferences vs Hive usage

### API Integration
**Location**: `lib/core/api/`

**Key Files**:
- `apiService.dart`: Main API service with Dio
- `apiEndPoints.dart`: API endpoint definitions
- `appConfig.dart`: App configuration and base URL

**Troubleshooting**:
- **API Calls Failing**: Check base URL and network connectivity
- **Authentication Errors**: Verify token handling
- **Timeout Issues**: Check API timeout configurations

## Common Issues & Solutions

### 1. App Crashes on Startup
**Possible Causes**:
- Firebase not initialized properly
- Hive database not initialized
- Missing dependencies
- Incorrect API configuration

**Solutions**:
- Check Firebase configuration in `firebase_options.dart`
- Verify Hive initialization in `main.dart`
- Run `flutter pub get` to install dependencies
- Check API base URL in `appConfig.dart`

### 2. Login/Authentication Issues
**Possible Causes**:
- Firebase configuration mismatch
- Google Sign-In SHA-1 fingerprint issues
- Network connectivity problems
- API endpoint errors

**Solutions**:
- Verify Firebase project configuration
- Check SHA-1 fingerprints in Firebase console
- Test network connectivity
- Check authentication API endpoints

### 3. Products Not Loading
**Possible Causes**:
- API connectivity issues
- Store ID not set
- Network timeout
- API response format changes

**Solutions**:
- Check network connectivity
- Verify store ID in API calls
- Check API timeout settings
- Validate API response format

### 4. Cart Issues
**Possible Causes**:
- Hive database not initialized
- Cart API errors
- User authentication problems
- Local storage corruption

**Solutions**:
- Check Hive initialization
- Verify cart API endpoints
- Ensure user is authenticated
- Clear app data and reinstall

### 5. Payment Gateway Failures
**Possible Causes**:
- Incorrect API keys
- Payment gateway configuration issues
- Network connectivity problems
- Currency/amount formatting issues

**Solutions**:
- Verify payment gateway credentials
- Check payment gateway configuration
- Test network connectivity
- Validate amount and currency formatting

### 6. Push Notifications Not Working
**Possible Causes**:
- Firebase configuration issues
- FCM token not generated
- Notification permissions not granted
- Backend notification service down

**Solutions**:
- Check Firebase project configuration
- Verify FCM token generation
- Request notification permissions
- Check backend notification service
